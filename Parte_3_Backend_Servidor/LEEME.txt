PARTE 3 — BACKEND (API REST)

Servidor de Finup hecho con Node.js y Express. Usa SQLite mediante el módulo integrado
node:sqlite, así que no hace falta instalar ningún servidor de base de datos ni configurar
credenciales.

- Código: usuario/Nuevo Archivo WinRAR ZIP/bakend - copia/server.js
- Base de datos: se crea sola la primera vez (finanzas_app.db) a partir de
  finanzas_app.sqlite.sql, en la raíz del proyecto.
- Requisito: Node.js 22.13 o superior.

Para ejecutarlo: en la carpeta "usuario/Nuevo Archivo WinRAR ZIP" corre npm install y luego
npm start. El servidor queda en http://localhost:3000. En Windows, iniciar.bat (en la raíz)
lo hace todo.
