# Frontend de Finup

Interfaz web de Finup hecha con Vue 3 y Vite. Se conecta a la API del backend en `http://localhost:3000/api` (ver `src/api.js`).

```bash
npm install
npm run dev
```

La documentación completa (funcionalidades, estructura, base de datos y API) está en el [README principal](../../../../README.md).
