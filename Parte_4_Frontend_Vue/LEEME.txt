PARTE 4 — FRONTEND (VUE 3 + VITE)

Interfaz de Finup en uso, para usuarios y administradores. Es la versión principal;
las Partes 1 y 2 son la versión antigua en HTML y ya no se usan.

- Código: usuario/Nuevo Archivo WinRAR ZIP/frontend/src
- Se conecta al backend en http://localhost:3000/api (archivo src/api.js).

Para ejecutarla: en la carpeta "frontend" corre npm install y luego npm run dev.
En Windows, iniciar.bat (en la raíz) arranca el backend y el frontend juntos.
